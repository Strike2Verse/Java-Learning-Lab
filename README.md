# Java-Learning-Lab

A structured journey through Java — from core basics to advanced concepts, with clear explanations and hands-on practice for every topic.

## 🎯 Repository Purpose

This repository is for relearning Java in a simple, organized, and project-focused way. The goal is to understand each concept properly before moving forward, while keeping the files clean enough to share on GitHub.

## ✨ Learning Approach

- Learn one concept at a time.
- Read the explanation before running the code.
- Practice with small programs before moving to larger projects.
- Keep examples simple, meaningful, and beginner friendly.
- Add folders only when they are needed by the current topic or project.

## 🧭 How To Use This Repository

1. Clone the repository:
   ```bash
   git clone https://github.com/Strike2Verse/Java-Learning-Lab.git
   ```
2. Move into the project folder:
   ```bash
   cd Java-Learning-Lab
   ```
3. Open the topic in `Explanations/`.
4. Read the explanation carefully.
5. Open the matching program in `Code/`.
6. Run the program and understand the output.
7. Practice by changing small parts of the code.
8. Update progress only after the topic is completed.
