# 🎮 Capstone Projects

This repository contains two original games built as capstone projects for the Java Learning Lab. Each game applies concepts from the full learning roadmap in a real, playable context.

---

## Project 1 — Signal Loss

> **Retro-cyberpunk grid puzzle game** built in pure Java (no engine, no libraries)

You control a data packet navigating a decaying circuit grid. Reach the Exit node before your signal hits zero. Nodes flip, teleport you, and drain your power — every move counts.

**Tech:** Java · Swing · Java2D · BFS Pathfinding · Procedural Generation · Audio Synthesis

**Status:** ✅ Complete

## Project 2 — Refract

> **Real-time laser drawing puzzle** built in HTML5 Canvas + JavaScript

A laser fires from the left wall. You click and drag to draw reflector lines on the screen. Guide the laser into the hole before it hits a wall. Speed increases every level.

**Tech:** HTML5 Canvas · Vanilla JavaScript · Vector Physics · Real-time Rendering

**Status:** 🟡 In Progress — Phase 1 of 12 complete
