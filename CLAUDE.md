# AI Usage Notes

This repository is built while relearning Java, with the help of Claude
(AI assistance) as a learning tool.

## How AI was used

- Explaining concepts before practicing them, one topic at a time
- Quick understanding checks (short Q&A) before moving on to practice
- Drafting practice programs and comments, which are then read, run, and
  modified to make sure the concept is actually understood
- Helping structure the repository, commit workflow, and documentation

## What this means

- Every file in this repository has been read, run, and understood before
  being committed — nothing is committed blindly
- Code style and comments may look consistent because of AI assistance,
  not because of prior professional experience
- The progress tracked in [PROGRESS.md](PROGRESS.md) reflects topics that
  have actually been studied and practiced, not just generated
- If you spot a bug, a better approach, or anything that could be
  improved, feel free to open an Issue — this repository is a learning
  project, and feedback is welcome
